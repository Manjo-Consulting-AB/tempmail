# Security Policy

## Reporting a vulnerability

Please do not open a public GitHub issue for security vulnerabilities.

Report suspected vulnerabilities privately to the maintainers through GitHub's private vulnerability reporting, or contact the repository owner through the contact details associated with the organization.

Please include:
- A clear description of the vulnerability
- Steps to reproduce
- The affected component or file
- Any relevant logs, screenshots, or proof of concept

We will acknowledge valid reports and coordinate remediation and disclosure with the reporter.

## Supported versions

The default branch is the actively maintained version.
